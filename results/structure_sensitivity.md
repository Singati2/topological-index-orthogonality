# §6.5 Structure sensitivity on the 75 decane isomers

Following the Furtula–Gutman convention used in MATCH 95:141-162 Table 2:

- `SS = std / mean` (coefficient of variation)
- `Abr = (max − min) / mean`
- `SA = SS / Abr` (higher → more gradual response)
