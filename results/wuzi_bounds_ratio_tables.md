# Ratio constants for the Wuzi ratio-bound theorem

Generated by `scripts/09_wuzi_bounds_tables.py`.

For each parameter triple (alpha, beta, gamma) and each classical BID index $I_h$ with edge contribution $h(i, j)$, this table gives

$$c_{\min}^{h} = \min_{(i,j)}\, \psi(i,j;\alpha,\beta,\gamma) / h(i,j),\quad c_{\max}^{h} = \max_{(i,j)}\, \psi/h,$$

over the 10 admissible degree pairs $(i, j)$ with $1 \le i \le j \le 4$.
The corresponding bound (Theorem B.1 of `docs/wuzi_bounds_strategy.md`) is

$$c_{\min}^{h}\, I_h(G) \;\le\; W(G; \alpha, \beta, \gamma) \;\le\; c_{\max}^{h}\, I_h(G).$$

The ratio bound is rigorous whenever $h(i, j) > 0$ on every admissible pair appearing in $G$. ABC vanishes at the $(1, 1)$ pair; the ABC ratio bound is therefore restricted to graphs without a $(1, 1)$ edge (any connected graph of order at least 3).

## Sanity check at exact reductions

When the Wuzi parameter triple coincides with a classical-index reduction, both $c_{\min}^h$ and $c_{\max}^h$ for that index should collapse to a constant (the Wuzi-classical identity is exact, not an inequality). Check the following rows in the table above:

- $(\alpha, \beta, \gamma) = (1, 0, 0)$ against $M_2$: should give $c_{\min}^{M_2} = c_{\max}^{M_2} = 1$.
- $(\alpha, \beta, \gamma) = (-1/2, 0, 0)$ against $R$: should give $c_{\min}^{R} = c_{\max}^{R} = 1$.
- $(\alpha, \beta, \gamma) = (0, -1, 0)$ against $H$: should give $c_{\min}^{H} = c_{\max}^{H} = 1/2$ (since $H = 2\,W(\cdot; 0, -1, 0)$).

If the table values disagree, there is a bug in `psi` or in the classical-index edge contribution `h(i, j)`.
