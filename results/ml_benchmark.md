# ML benchmark: does orthogonality screening preserve predictive performance?

Generated by `scripts/11_ml_benchmark.py`. RandomForest (300 trees, fixed seed) trained under 5-fold cross-validation (stratified for the classification dataset). All feature selection (PCA, pairwise pruning, combined pruning) is performed inside each training fold to avoid test-fold information leakage. Reported values are mean +/- std across the 5 folds.

Feature configurations:

- **full** -- all 30 baseline indices
- **pca_95** -- top-k principal components on the training fold, cumulative variance >= 95%
- **pairwise_pruned** -- greedy redundancy filter at |r| < 0.95 on the training fold
- **combined_pruned** -- pairwise filter plus |partial corr with target| >= 0.1 on the training fold

## Interpretation

Compare the `full` and `pairwise_pruned` rows within each dataset.
If the mean +/- std intervals overlap, the screen has reduced the
feature count without statistically meaningful loss in predictive
performance. The combined-criterion screen is more aggressive; on
datasets where the underlying topology-target partial-correlation
structure is weak, the screen may retain zero features in some or
all folds (reported as '---').
