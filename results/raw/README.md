# Raw output dumps

The `.txt` files in this directory are the auto-generated text logs
from `scripts/01_baseline_correlations.py` (`<ds>_baseline_summary.txt`)
and `scripts/02_wuzi_grid_search.py` (`<ds>_wuzi_summary.txt`) for
each dataset `<ds>` in `{esol, freesolv, lipophilicity}`.

They are kept here for reproducibility and audit; the polished
narrative is in the top-level `results/*.md` files
(`cross_dataset_summary.md`, `ml_benchmark.md`,
`octane_competitor_comparison.md`, `wuzi_extremal_trees.md`,
`wuzi_bounds_ratio_tables.md`, `wuzi_degeneracy.md`,
`structure_sensitivity.md`).

These raw dumps are not cited from either manuscript or from the
top-level `results/` narratives.
